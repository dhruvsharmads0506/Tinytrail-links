<h1>🔗 TinyTrail — Smart URL Shortener & Analytics Platform</h1>
<p align="center"><b>Full Stack Project</b></p>

<h2>📝 Project Description</h2>
<p>
TinyTrail is a full-stack URL shortening web application that allows users to create custom short links, generate QR codes, and track link performance through real-time analytics.
The platform supports secure authentication for link management while keeping short links publicly accessible for anyone to use.
</p>
<p>
Users can monitor clicks by device type and geographic location, making it useful for marketing campaigns, sharing resources, and tracking engagement.
</p>

<h2>🚀 Features</h2>
<ul>
  <li>Create custom short URLs</li>
  <li>Public redirection without login</li>
  <li>QR code generation & download</li>
  <li>Click analytics tracking</li>
  <li>Device detection</li>
  <li>Country & city tracking</li>
  <li>User authentication & dashboard</li>
  <li>Delete and manage links</li>
  <li>Responsive modern UI</li>
  <li>Deployed on Netlify</li>
</ul>

<h2>🛠 Tech Stack</h2>
<h3>Frontend</h3>
<ul>
  <li>React (Vite)</li>
  <li>React Router</li>
  <li>Tailwind CSS</li>
  <li>ShadCN UI</li>
</ul>

<h3>Backend / Database</h3>
<ul>
  <li>Supabase (PostgreSQL + Auth + Storage)</li>
</ul>

<h3>Analytics</h3>
<ul>
  <li>IP Geolocation API</li>
  <li>UA-Parser (device detection)</li>
</ul>

<h3>Deployment</h3>
<ul>
  <li>Netlify</li>
</ul>
